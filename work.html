Featured case study
CES Trainer — AI Training Platform
Client: Asseco  ·  Role: Project Manager + UI/UX

An intelligent training assistant that lets trainees ask questions across course videos and PDFs and get cited answers — with the exact video timestamp and highlighted document passage behind every response (RAG over Azure OpenAI + Qdrant; React + Python).

Problem
Trainees lost time manually searching across dozens of training videos and PDF manuals to find answers — with no way to trace where an answer came from.
What I did
Owned scope and delivery for an enterprise client across 3+ sprints, coordinating backend, frontend, and an AI/retrieval workstream. Sequenced milestones from core RAG backend → learning cockpit UI → PDF pipeline, and contributed the dual-pane video/PDF interface design.
Result
A working platform that answers learner questions with cited sources, jump-to-timestamp video, and highlighted PDF passages — replacing slow manual lookup with semantic, traceable search.
